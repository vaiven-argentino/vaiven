# pipeline/fuentes/

Un módulo por API (datos.gob.ar, CSV de distribuciones de datos.gob.ar, BCRA): descarga el archivo, calcula el checksum y guarda el snapshot con fecha, URL y licencia.

La API del BCRA no se usa por ahora: su aviso legal no permite el uso comercial sin autorización, lo que no es compatible con CC BY 4.0 (ver `docs/NOTAS_FASE1.md`).

**Se llenó en:** fase 1.
